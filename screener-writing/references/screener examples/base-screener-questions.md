## Recruiting Notes

**Quota Management:**

*   **Enterprise (5)**: Q2 = "Enterprise" OR "Large Private Company" OR (Q3 = 200+ employees)
*   **Startup (3)**: Q2 = "Startup" OR (Q3 = 2-199 employees)
*   **Azure users (4)**: Q12 includes "Microsoft AI Foundry" OR Q14 includes "Microsoft Azure"
*   **Non-Azure users (4)**: None of the above Azure indicators

**Critical Qualifiers:**

1.  Hands-on developer (Q6 = accepts)
2.  Building AI apps regularly (Q5 = primary or regular)
3.  Builds or configures AI agents/workflows (Q7 = must select)
4.  Uses BOTH tools AND knowledge grounding (Q8 = must select both)
5.  Currently in Development or Production stage (Q11)

**Diversity Considerations:**

*   Aim for variety in company types and industries
*   Include different AI use cases and patterns
*   Balance between Azure-native and multi-cloud users
*   Include both framework users and custom builders

**Expected Pass Rate:** ~15-20% (strict criteria on hands-on + tools + knowledge)
